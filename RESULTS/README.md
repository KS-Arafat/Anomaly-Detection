# Results

This directory contains all the metrics from models trained on Random forest, XGboost, Logistic Regresion, so on. We used 2 datasets: [NSL-KDD](https://www.unb.ca/cic/datasets/nsl.html) and [TON_IoT](https://research.unsw.edu.au/projects/toniot-datasets). We have excluded UNSW as we had better results with other 2s. In the end we used Ton_IoT as our main dataset. Also we have simple design of our system architecture.
