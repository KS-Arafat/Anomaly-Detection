# Others

## Overview

This folder contains supplementary materials and weekly class updates for the project. Like project proposal, reports, literature reviews, proposed solution, presentations and a ~1 min videos demo of our porject.

## Conventions

- Use the folder name "ClassNN" for each class session.
- Place session notes in "UpdateNN.md" inside the corresponding class folder.
- Prefer plain Markdown headings, short summaries, and dated entries at the top.

## Usage

- Open the appropriate UpdateNN.md to read class notes.
- Add new class folders following the same naming pattern for future sessions.

## Contribution

- Create or edit files via pull requests or by adding commits to the repository.
- Keep updates focused, dated, and versioned (UpdateNN.md).
